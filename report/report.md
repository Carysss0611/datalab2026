### bitAnd

```c
int bitAnd(int x, int y) {
    return ~(~x | ~y);
}
```

思路：
根据德摩根定律，两个变量的按位与，等价于两个变量分别取反后再按位或的整体取反。

### bitXor

```c
int bitXor(int x, int y) {
    return ~(~x & ~y) & ~(x & y);
}
```

思路：
异或是对应位不同则结果为1，相同则结果为0，可表示为 (x | y) & ~(x & y)，再利用德摩根定律将 x | y 转换为 ~(~x & ~y)。

### samesign

```c
int samesign(int x, int y) {
    if (!x && !y)
    {
        // 都等于0
        return 1;
    }
    else if (!(x && y))
    {
        // 其中一个等于0
        return 0;
    }
    else
    {
        // 都不等于0
        return !((x ^ y) >> 31);
    }
}
```

思路：
0符号位为0但不是正数，需要单独判断。若!x && !y，两数均为0，则返回1；若!(x && y)，两数中有一个为0，则返回0；其余情况则需判断符号位是否相同，若相同则返回1，不同则返回0，所以用异或后右移31位取出符号位再取反。
